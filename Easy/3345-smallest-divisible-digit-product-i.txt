Time Complexity: O(n)
Space Complexity: O(1)

Code (Brute Force):
class Solution {
    public int smallestNumber(int n, int t) {
        int m=n;
        for(int i=0;i<10;i++){
            int temp=m;
            int product=1;
            while(temp>0){
                product*=temp%10;
                temp=temp/10;
            }
            if(product%t==0) return m;
            m++;
        }
        return -1;
    }
}
